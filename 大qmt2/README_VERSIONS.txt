大 QMT2 竞价选股策略 - 版本变更说明
======================================

版本保留规则
------------
每次常规更新均新增“日期 + v序号”的 Python 文件，不覆盖已有日期版本。
文件为 GBK 编码，复制到大 QMT 时请保持原编码。若用户明确要求覆盖某个
指定版本文件，则以该明确要求为准。

--------

2026-09-27.1
文件：DAqmt2_jingjia_filter_20260927_v1.py
说明：目标交易日09:00前启动即全股票池下载日线，取消原06:00启动限制与08:50截止。
      下载结束检查真实缓存，中文显示有效、缺失数量及是否满足缺失不超过20只。
      09:00若启动下载仍未结束，则等待完成后核验，避免中途检查和重复下载。
      早晨核验缺失不超过20只直接准备选股；超过20只再进行一次全股票池下载，
      完成后不再限制总体缺失数量，仅以日期完整的有效股票继续原定选股流程。
      下载与缓存核验互斥，同日早晨准备完成后重复回调不再下载。
      不改变竞价采样窗口、筛选条件和下单时间；下载过慢仍可能错过原定采样。

文件：DAqmt2_jingjia_filter_20260927_v2.py
